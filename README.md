# Minor-Project-06-Flip-Flops-Single-Port-RAM
Verilog design and verification of Flip-Flops and an 8×8 Single-Port RAM using a testbench and waveform simulation.
MINOR PROJECT – 06

Flip-Flops & Single-Port RAM

Project Overview

This project focuses on understanding Flip-Flops and designing an 8×8 Single-Port RAM using Verilog HDL.

The project includes Verilog coding, testbench development, simulation and verification of read and write operations.

Part A: Flip-Flops

The following concepts are studied:

1. D Flip-Flop
2. JK Flip-Flop
3. T Flip-Flop
4. Level-Triggered Latch
5. SR Latch
6. D Latch

Part B: Single-Port RAM

Objective: Design an 8×8 Single-Port RAM and verify its read and write operations using a Verilog testbench.

Specifications

Specification| Details
Memory Depth| 8 Locations
Data Width| 8 Bits
Address Width| 3 Bits
Clock| Positive Edge Triggered
Write Enable| Active HIGH
Read Operation| Write Enable = 0
Write Operation| Write Enable = 1

Tasks

1. Draw the block diagram.
2. Write the Verilog design.
3. Write the testbench.
4. Verify read and write operations.
5. Display the output waveform.

Tools Used

- Verilog HDL
- ModelSim / Vivado
- Digital Design and Simulation

Expected Result

Successful design and verification of an 8×8 Single-Port RAM with correct read and write operations.
